VOLTIA - sitio web adaptable a móviles

ARCHIVOS
- index.html: estructura y textos
- styles.css: diseño adaptable para móvil, tablet y escritorio
- script.js: año automático
- assets/: imágenes recortadas de la referencia entregada

ANTES DE PUBLICAR
1. Abre index.html para probar la página localmente.
2. En index.html, reemplaza +56900000000 por el teléfono real en los enlaces tel: y wa.me.
3. Revisa precios, cobertura, tiempos y garantía antes de publicar. El diseño evita prometer datos que no fueron confirmados.
4. Sube la carpeta completa a tu hosting manteniendo la estructura de archivos.

No requiere frameworks ni instalación.
